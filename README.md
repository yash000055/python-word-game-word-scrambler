# Word Scramble Game in Python

## Description :
This project is a simple word puzzle game written in Python where the program randomly selects a word from a predefined dataset, scrambles its letters, and asks the user to guess the original word. The user is given three attempts to guess the correct word, making the game interactive and logic-driven.

## How the Game Works :
- A word is randomly selected from a predefined dataset.
- The letters of the word are shuffled to create a scrambled version.
- The scrambled word is displayed to the user.
- The user has three attempts to guess the original word.
- If the user guesses correctly within the attempts, they win.
- If all attempts are used, the correct word is revealed.

## Features :
- Random word selection
- Letter scrambling using Python logic
- Limited attempts for added challenge
- Case-insensitive user input
- Clear win and game-over messages

## Dataset Details :
- The dataset contains words related to:
  - Science and research
  - Artificial Intelligence and Data Science
  - College and academic life
  - Friendship and teamwork
- All words are stored in uppercase for consistency.
